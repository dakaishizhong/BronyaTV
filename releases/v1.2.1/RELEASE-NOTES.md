# BronyaTV 1.2.1

- 内置 TrueHD / MLP 软件音频解码，补齐播放器的音频兼容路径。使用 PCM 输出，不提供 TrueHD Atmos 直通；E-AC-3 等其他音频继续使用原来的系统路径。
- 分开处理音频与视频解码故障，音频失败不再触发 4K 视频的软件解码回退。HEVC、HDR 和 Dolby Vision 视频继续使用设备解码器。
- 修正快进后的缓冲判定：旧位置保留的内存不能单独触发播放；前向缓冲不足时允许有限恢复余量。
- 快进后同时检查播放时钟和渲染帧，检测到输出停滞时尝试重建一次播放器，保留进度和播放／暂停状态。
- 拦截遥控器返回键重复事件，防止一次长按连续退出多个页面；取消首页恢复到前台时的定时整页刷新。
- 原有页面、播放选项和设置保留，诊断可识别实际使用的 FFmpeg 软件音频解码器。

沿用发布签名，可覆盖安装旧版并保留账号及设置。APK 可使用 SHA256SUMS 校验。

58 项单元测试、Release 构建与 lint、原生库打包及签名检查通过。本次未进行界面、实体电视 TrueHD 或杜比音频播放实测，实际兼容性仍需设备确认。验证范围见 [VALIDATION.md](https://github.com/dakaishizhong/BronyaTV/blob/v1.2.1/releases/v1.2.1/VALIDATION.md)。
