# BronyaTV 1.1.0

沿用包名 tv.ember.client 和发布签名，versionCode 5；可覆盖升级 1.0.3 并保留登录及手动连接数。

## 网络与设备判断

Android 网络框架和厂商固件可能配置 TCP 缓冲上限；普通应用无法在无 root 下修改全局内核参数。本版继续采用独立连接，无需 root。手动 SO_RCVBUF 仍受系统限制；保持系统自动更有利于保留自动调节。

- 第一段先读取并校验最多 64KiB，随即启动并发预取，缩短开播和跳转时等待完整大分段的时间。
- 新装分段接收默认自动：已知码率至少 12Mbps 且预算充足时 4 路；至少 6Mbps 或未知码率且预算充足时 2 路；其他使用单连接。低内存或预算不足时降为单连接。已有手动设置保留。
- 预取仍采用 HTTP/1.1 独立连接、有序合并、Range/大小/文件版本验证和原签名地址。服务器不支持 Range 时，在当前播放会话中记住单连接回退，跳转时避免重复无效探测。
- 播放结束或数据源关闭及时释放预取引用。海报网络并发限制为 3，位图尺寸与缓存随堆上限缩小，并响应系统内存回收提示。

## 登录和开播

暗色渐变、青绿色焦点、圆角卡片与分组设置。账号登录和 Token 登录分别展示所需字段；可显示密码，提交中防止重复请求，失败时显示具体原因。省略协议的有效域名/IP 使用 HTTPS，显式 HTTP、端口和代理前缀保留。

密码和 Token 输入不保存到视图状态。退出仅保留服务器与用户名输入提示；会话仍用 Keystore 加密。每个进程首次读取后缓存会话，减少海报列表重复解密；旧版加密会话首次读取时补齐登录提示。

详情页使用一次性、30 秒有效的内存交接传递影片与播放信息给播放器，减少重复详情与 PlaybackInfo 请求。账号、影片、片源不匹配或超时即丢弃；地址不写入 Intent 或偏好设置。详情页的版本列表缓存 15 秒；单版本可直接打开，多版本继续明确选择。

## 跳转、缓存和选择

- 默认预缓冲 2 秒，旧的显式设置保留。内存请求增加自动及 16/32/64/128/256MB，小堆设备仍按安全预算限制。
- 控制栏隐藏时左右键预览；松开后等待 280ms 合并连续按键，再执行一次跳转。长按按重复次数加速，单次步长最高 60 秒；确定键立即跳转，返回键取消。控制栏显示时保留原有焦点导航。
- 跳转后的恢复阈值为最多 1.2 秒，按倍速调整，避免反复等满初次预缓冲。指定时间支持“分:秒”和“时:分:秒”，拒绝无效时间并限制在视频范围内。
- 回退缓存默认最多 5 秒，可关闭或选择 15/30 秒；按声明码率限制为播放预算的四分之一，低内存或未知码率时关闭，与前向缓冲共享 allocator。Keyframe 保留和实际编码影响实际占用；总字节阈值仍限制继续加载。
- 播放中可切换片源并保留进度；倍速 0.5/0.75/1/1.25/1.5/2、适应/裁切/拉伸、字幕 80/100/120/140%。默认音轨/字幕语言可选中文、英语、日语或自动。
- 轨道列表显示当前选择，视频轨道不提供关闭项；音频可静音，字幕可关闭。目录与搜索结果支持四种服务端排序；首页保持继续观看、最近添加、分类结构。

## 诊断

普通播放菜单提供 SoC/硬件型号、Board、可用 CPU 核、APP 单核等效 CPU、APP 最大堆/已用堆和实际回退保留时间。系统可用内存与应用堆不是同一个预算。保留片源格式、真实解码器/输入、音频欠载、帧统计、缓冲与多连接 HTTP 信息。

SO_RCVBUF 是系统报告值，不是服务端看到的广告窗口，也不是所有连接的总和；网络速率包含预取和等待，缓冲充足停取流时降低属于正常行为。查询值、用户信息、片段仍遮盖。
