# Ember TV 1.0.3

Android TV Emby 客户端，最低 Android 6.0，支持 ARM 32 位和 64 位电视。

- 增加可选的 2/4/8 路分段接收，用于高延迟、单连接接收窗口受限的链路。
- 增加播放诊断：片源容器、实际视频/音频格式、解码器、下载速率、连接数、缓冲和内存信息。
- 延续 1.0.2 的播放地址修复及 1.0.1 的电视启动兼容性修复。

APK 沿用现有发布签名，可覆盖安装旧版并保留登录和设置。下载后可用同目录 SHA256SUMS 校验文件。

电视链路测试：设置 → 网络接收缓冲选“系统自动”，分段接收选“4 路”，退出播放后重新打开同一片源；也可比较 8 路。具体效果仍需电视实测。

已完成单元测试、模拟器设备测试和签名发布包验证；尚未确认用户电视上的速度改善。
