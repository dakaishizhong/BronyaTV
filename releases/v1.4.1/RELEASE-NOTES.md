# BronyaTV 1.4.1

Adjusts the TV layout to the reference proportions while preserving server content and saved language preferences.

- Enlarges the Home title and moves resume status and source badges above it. Fits Continue watching and Recently added on the first screen.
- Removes ordinary sidebar button borders. Active destinations use a translucent cyan outline and subtle glow; Emby and Settings stay at the bottom.
- Calculates five complete landscape cards from the available viewport width, with approximately 2.6:1 artwork. Titles and metadata sit below the image on the page background.
- Restricts card focus outlines and zoom to artwork. Reserves room for zoom and keeps already visible rows still during vertical navigation.
- Removes browser breadcrumbs and places Sort and Refresh in the top-right menu, also accessible with the remote Menu key. Keeps the clock.
- Applies the shared rail, card and title treatment to Details, Search and Settings. Keeps the existing playback controls, sources, tracks and other settings.
- Keeps English and Simplified Chinese switching and the selected language. Both README editions use new English screenshots.

Movie artwork, media decoders and playback networking are unchanged. Quality, rating, progress and remaining-time labels use server metadata; sparse rows are not filled with duplicate content.

Uses the 1.4.0 signing key and supports Android 6.0 or later. Installs over 1.4.0; versions 1.3.0 and earlier require uninstalling first.

Validation: [VALIDATION.md](https://github.com/dakaishizhong/BronyaTV/blob/v1.4.1/releases/v1.4.1/VALIDATION.md).
