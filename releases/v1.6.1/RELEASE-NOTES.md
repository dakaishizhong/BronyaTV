# BronyaTV 1.6.1

Play/Pause is fixed at screen center. The player has six circular controls with consistent vector icons, balanced spacing and stable focus geometry. The rounded timeline shows played and buffered progress with a clear focused thumb. The speaker shortcut is removed; audio track selection remains in Playback options.

Removed the top-left Back buttons from Details and every settings editor. The remote Back key keeps the existing return layers and restores focus. Shared action buttons, sidebar icons, settings category badges and dialog typography now use consistent sizes, color contrast and restrained cyan focus effects.

The Media3 player, native decoder libraries, network buffering, source validation, subtitles, episodes, external-player options, cached metadata and server-library browsing remain available. English is the default documentation/screenshot language; the saved English/Chinese app preference is preserved.

Validation and device limits: [VALIDATION.md](VALIDATION.md).
