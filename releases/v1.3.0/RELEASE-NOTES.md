# BronyaTV 1.3.0

- 在已有 TrueHD / MLP 路径上补齐 DTS / DTS-HD 软件音频解码，使用 PCM 兼容输出。视频继续使用设备解码器；此音频路径不保留 TrueHD Atmos 或 DTS:X 对象元数据，也不提供这些格式的码流直通。
- 加入独立于内存播放队列的磁盘提前缓存：播放优先读缓存，缺失部分继续走原网络取流。容量满时淘汰较旧的数据，跳转时取消旧位置的预取，退出、切集和换源时停止预取。
- “设置 → 网络与缓存”新增磁盘缓存容量、磁盘提前缓存和清空功能。默认自动容量（最多 512 MiB）与提前 60 秒；可关闭，或选择 256 MiB 至 8 GiB、15 秒至 5 分钟。容量根据可用存储缩减，预留系统空间，无需 root 或存储权限。
- 调整高码率缓冲设计：磁盘模式降低自动内存目标，共享前台与预取的接收内存预算；自动模式在高码率片源上可使用 8 路接收，并增加启动及重缓冲时间。手动选择的连接数仍优先。
- 补齐单连接服务忽略 Range 时的识别，避免持续提前请求造成重复下载；外置字幕长度不再覆盖主视频长度。
- 性能与诊断新增磁盘前向缓存、占用、读取命中、预取状态，以及最近故障的音频、视频或取流分类。

磁盘缓存用于 MP4、MKV 等原文件播放；HLS / DASH 保持播放器缓冲。当前播放器中的跳转可以复用缓存，切换片源或重建播放器使用新的缓存标识；缓存不作为离线影片库。

沿用旧版签名，可覆盖安装并保留账号和设置。67 项单元测试、3 项 Android TV 模拟器专项检查、Release 构建与 lint、原生库与签名检查通过。模拟器 DTS 检查使用生成的 AVC / DTS 核心音轨；实体电视的 DTS-HD、DTS:X 和高码率网络效果未实测。验证范围见 [VALIDATION.md](https://github.com/dakaishizhong/BronyaTV/blob/v1.3.0/releases/v1.3.0/VALIDATION.md)。
