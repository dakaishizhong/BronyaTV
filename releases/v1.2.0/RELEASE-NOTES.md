# BronyaTV 1.2.0

- 只保留账号密码登录，删除 Token 登录入口；加密会话与自动登录继续保留。
- 更新登录、首页、详情、设置、播放器和选择菜单：简洁暗色层次、白色焦点、圆角海报与按钮、分类设置侧栏；统一点击及菜单返回行为。
- 短按和长按快进／快退步长分别可调，默认 10 秒和 30 秒。连续按键预览合并后跳转，返回取消。
- 支持上一集、下一集、跨季连播和自动播放下一集。
- 支持设置跳过片头、片尾的秒数（0–600 秒，0 为关闭）。片头不会覆盖已超过片头的续播；片尾连播有 5 秒倒计时，按返回可取消。
- 播放诊断区分片源声明、实际解码画面、Surface、显示模式，新增首帧、解码器色彩输出、Dolby Vision 解码路径、AudioTrack 编码／采样率／声道和 Dolby Atmos 码流信息。最终屏幕或接收设备模式无法确认时明确显示未确认。
- 优化首页返回时的选中位置、连续剧切换和取消任务、播放菜单重复点击及逐帧诊断开销；保留多路接收、字幕、片源切换和缓冲设置。
- 项目介绍只展示功能与使用方法，历史改动集中到对应版本说明。

沿用发布签名，可覆盖安装旧版并保留账号及设置。APK 下载后可使用 SHA256SUMS 校验。验证记录见同目录 VALIDATION.md。
